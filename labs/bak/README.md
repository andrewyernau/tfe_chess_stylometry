# Backup Directory (bak/)

Este directorio contiene archivos antiguos que ya no están en uso por el notebook principal `002_blocks_siamese_cnn.ipynb`, pero se mantienen por si son útiles en el futuro.

## Archivos almacenados:

### Archivos bak_* (versiones antiguas)
- `bak_extract_player_games.py` - Versión antigua de extracción de partidas
- `bak_monitor_pipeline.py` - Monitor antiguo del pipeline
- `bak_parse_games_to_images.py` - Parser antiguo de juegos a imágenes
- `bak_pipeline_stylometry.py` - Pipeline antiguo de estilometría
- `bak_pipeline_stylometry_notebook.py` - Versión notebook del pipeline antiguo
- `bak_synchronize_images.py` - Sincronizador antiguo de imágenes

### Utilidades no usadas
- `cleanup_temp_files.py` - Limpieza de archivos temporales
- `reload_modules.py` - Recarga de módulos

### Versiones anteriores (no-v002)
- `generate_decision_heatmaps.py` - Versión anterior de generación de heatmaps (reemplazado por v002_*)
- `generate_images_synchronized.py` - Versión anterior de generación de imágenes sincronizadas
- `pipeline_stylometry_by_event.py` - Pipeline anterior por eventos

## Nota
Estos archivos NO son necesarios para el funcionamiento actual del sistema, pero se conservan por precaución.
Si en algún momento se necesita alguna funcionalidad de estos archivos, pueden ser consultados aquí.
